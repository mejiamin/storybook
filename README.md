## Storybook | 6 уроков

Для уверенной работы со Storybook в твоем текущем стеке (React, TypeScript, CSS Modules) нам понадобится **6 структурированных уроков**.

Этого будет достаточно, чтобы научиться изолированно разрабатывать, тестировать и документировать UI-компоненты.

Вот подробный план нашего интенсива:

### План обучения Storybook

1. **Урок 1: Интеграция и интерфейс.** Правильный запуск Storybook внутри существующего проекта на Vite и разбор того, как устроена его панель управления.

2. **Урок 2: Написание первой истории (Story).** Создание изолированного компонента (например, UI-кнопки) и описание ее базового состояния с полной типизацией TypeScript.

3. **Урок 3: Интерактивные пропсы (Args).** Настройка вкладки Controls. Мы сделаем так, чтобы текст, цвет и размер компонента можно было менять кликами прямо в браузере без изменения кода.

4. **Урок 4: CSS Modules в изоляции.** Подключение и настройка локальных классов (CSS Modules), чтобы стили компонентов корректно подгружались в песочнице Storybook.

5. 👉 **Урок 5: Декораторы (Decorators).** Добавление глобальных оберток — например, центрирование компонентов на экране, добавление отступов или провайдеров тем.

6. **Урок 6: Полезные аддоны (Actions и Viewport).** Отслеживание кликов (эмуляция функций через Actions) и проверка адаптивности компонентов на мобильных и десктопных экранах.

## Урок 5: Декораторы (Decorators)

Декораторы — это компоненты-обертки для твоих историй. Они позволяют добавить дополнительную разметку или контекст вокруг компонента, не меняя его собственный исходный код.

В реальных проектах декораторы обычно решают две задачи:

1. **Визуальное оформление:** Отцентрировать компонент на экране, задать фиксированную ширину контейнера или поместить его на темный фон для проверки контрастности.
2. **Обертки контекста:** Если компонент читает данные из Redux-стора или использует Context API (например, для управления состоянием корзины покупок), Storybook выдаст ошибку, так как рендерит компонент «в вакууме». Декоратор позволяет легко обернуть историю в нужный `<Provider>`.

### Локальный декоратор (для конкретного компонента)

Сейчас наша кнопка прилипает к левому верхнему углу песочницы. Давай добавим декоратор, который поместит её в центрированный контейнер.

Открой `Button.stories.tsx` и добавь массив `decorators` внутрь объекта `meta`:

```tsx
import type { Meta, StoryObj } from '@storybook/react';
import { Button } from './Button';

const meta: Meta<typeof Button> = {
  title: 'UI/Button',
  component: Button,
  tags: ['autodocs'],
  // Добавляем декоратор на уровень всего компонента
  decorators: [
    (Story) => (
      <div style={{ 
        padding: '3em', 
        display: 'flex', 
        justifyContent: 'center', 
        border: '2px dashed #ccc' 
      }}>
        {/* Компонент из текущей истории
         будет отрендерен вместо <Story /> */}
        <Story />
      </div>
    ),
  ],
  argTypes: {
    // ... твои настройки Controls из прошлого урока ...
  },
};

export default meta;
```

Как только ты сохранишь файл, **все** истории (Primary, Secondary, Large) для этой кнопки будут отрисовываться внутри блока с пунктирной рамкой по центру экрана.

### Глобальные декораторы

Если у тебя появится обертка, которая нужна абсолютно всем компонентам приложения (тот же Redux Provider или обертка для роутинга), тебе не придется копировать этот код в каждый `.stories.tsx`.

Глобальные декораторы добавляются в знакомый нам файл **`.storybook/preview.ts`**:

```tsx
import type { Preview } from '@storybook/react';
import '../src/global.css';

const preview: Preview = {
  // Этот декоратор применится 
  // ко всем компонентам во всем Storybook
  decorators: [
    (Story) => (
      <div className="global-theme-wrapper">
        <Story />
      </div>
    ),
  ],
  parameters: { /* ... */ },
};

export default preview;
```

Добавь центрирующий декоратор в файл кнопки и посмотри, как преобразится Canvas в браузере.
