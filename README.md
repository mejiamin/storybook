## Storybook | 6 уроков

Для уверенной работы со Storybook в твоем текущем стеке (React, TypeScript, CSS Modules) нам понадобится **6 структурированных уроков**.

Этого будет достаточно, чтобы научиться изолированно разрабатывать, тестировать и документировать UI-компоненты.

Вот подробный план нашего интенсива:

### План обучения Storybook

**Урок 1: Интеграция и интерфейс.** Правильный запуск Storybook внутри существующего проекта на Vite и разбор того, как устроена его панель управления.
<br />
**Урок 2: Написание первой истории (Story).** Создание изолированного компонента (например, UI-кнопки) и описание ее базового состояния с полной типизацией TypeScript.
<br />
**Урок 3: Интерактивные пропсы (Args).** Настройка вкладки Controls. Мы сделаем так, чтобы текст, цвет и размер компонента можно было менять кликами прямо в браузере без изменения кода.
<br />
**Урок 4: CSS Modules в изоляции.** Подключение и настройка локальных классов (CSS Modules), чтобы стили компонентов корректно подгружались в песочнице Storybook.
<br />
**Урок 5: Декораторы (Decorators).** Добавление глобальных оберток — например, центрирование компонентов на экране, добавление отступов или провайдеров тем.
<br />
**Урок 6: Полезные аддоны (Actions и Viewport).** Отслеживание кликов (эмуляция функций через Actions) и проверка адаптивности компонентов на мобильных и десктопных экранах.

## Урок 1: Интеграция и интерфейс.

Поскольку у тебя уже настроен проект на **React + Vite + TypeScript**, интеграция Storybook пройдет максимально гладко. Разработчики Storybook создали специальную команду, которая сама определяет твой стек и настраивает всё необходимое под капотом.

1. **Установка и настройка (Установлено):** Выполни в терминале корня проекта.
Останови текущий сервер разработчика (если он запущен) и введи эту команду:

```bash
npx storybook@latest init
```

Эта команда проанализирует проект, скачает нужные пакеты, добавит скрипты запуска в `package.json` и создаст базовую конфигурацию, совместимую с Vite.


2. **Запуск Storybook:** Откроется в новой вкладке браузера.
После успешной установки запусти песочницу отдельной командой:

```bash
npm run storybook
```

По умолчанию Storybook запустится на порту `6006` и сам откроет страницу в браузере.

## Что изменилось в проекте?

После выполнения команды `init` в твоем проекте появились две важные папки:

* **`.storybook/`** — системная папка конфигурации. В ней лежат файл `main.ts` (отвечает за то, где Storybook должен искать компоненты) и `preview.ts` (отвечает за глобальное отображение — сюда мы позже подключим глобальные стили).
* **`src/stories/`** — папка с готовыми примерами (кнопка, шапка, страница). Storybook сгенерировал их специально, чтобы показать, как всё работает. На следующем уроке мы их удалим и создадим свой UI-компонент с нуля.

## Знакомство с интерфейсом

Когда откроется браузер, обрати внимание на три главные зоны:

1. **Сайдбар (слева):** Дерево всех твоих компонентов. Сейчас там лежат примеры (Button, Header, Page).
2. **Холст / Canvas (по центру):** Сама "песочница", где изолированно рендерится выбранный компонент.
3. **Панель аддонов (снизу):** Твой главный инструмент тестирования. Открой вкладку **Controls** — она позволяет менять свойства компонента (текст, цвет, размер) прямо мышкой без изменения кода.

Покликай по примерам кнопок в сайдбаре и попробуй поменять их настройки в панели Controls.
