## Storybook | 6 уроков

Для уверенной работы со Storybook в твоем текущем стеке (React, TypeScript, CSS Modules) нам понадобится **6 структурированных уроков**.

Этого будет достаточно, чтобы научиться изолированно разрабатывать, тестировать и документировать UI-компоненты.

Вот подробный план нашего интенсива:

### План обучения Storybook

1. **Урок 1: Интеграция и интерфейс.** Правильный запуск Storybook внутри существующего проекта на Vite и разбор того, как устроена его панель управления.

2. **Урок 2: Написание первой истории (Story).** Создание изолированного компонента (например, UI-кнопки) и описание ее базового состояния с полной типизацией TypeScript.

3. **Урок 3: Интерактивные пропсы (Args).** Настройка вкладки Controls. Мы сделаем так, чтобы текст, цвет и размер компонента можно было менять кликами прямо в браузере без изменения кода.

4. **Урок 4: CSS Modules в изоляции.** Подключение и настройка локальных классов (CSS Modules), чтобы стили компонентов корректно подгружались в песочнице Storybook.

5. **Урок 5: Декораторы (Decorators).** Добавление глобальных оберток — например, центрирование компонентов на экране, добавление отступов или провайдеров тем.

6. 👉 **Урок 6: Полезные аддоны (Actions и Viewport).** Отслеживание кликов (эмуляция функций через Actions) и проверка адаптивности компонентов на мобильных и десктопных экранах.

## Урок 6: Полезные аддоны (Actions и Viewport)

Финишная прямая! В этом последнем уроке мы разберем два важнейших инструмента для тестирования компонентов: отслеживание событий (кликов) и проверку адаптивности.

Оба этих инструмента работают через систему **Аддонов (Addons)** — встроенных плагинов Storybook.

## 1. Actions (Отслеживание событий)

Как понять, что кнопка действительно нажимается и передает событие наверх, если у нас нет основного приложения, которое могло бы вывести `console.log`? Для этого нужен аддон Actions.

Сначала давай научим нашу кнопку принимать клики. Обнови `Button.tsx`:

```tsx
interface ButtonProps {
  label: string;
  variant?: 'primary' | 'secondary';
  size?: 'small' | 'large';
  /** Обработчик клика */
  onClick?: () => void; // <-- Добавили пропс
}

export const Button = ({ 
  label, 
  variant = 'primary', 
  size, 
  onClick 
}: ButtonProps) => {
  const sizeClass = size ? styles[size] : '';
  
  return (
    // Передаем onClick в HTML-тег
    <button 
      className={`
        ${styles.btn} 
        ${styles[variant]} 
        ${sizeClass}
      `} 
      onClick={onClick}
    >
      {label}
    </button>
  );
};
```

Теперь научим Storybook "слушать" эти клики. В современных версиях Storybook для этого используется функция `fn()` из пакета тестирования. Обнови `Button.stories.tsx`:

```tsx
import type { Meta, StoryObj } from '@storybook/react';
// Импортируем функцию-шпион
import { fn } from '@storybook/test';
import { Button } from './Button';

const meta: Meta<typeof Button> = {
  title: 'UI/Button',
  component: Button,
  tags: ['autodocs'],
  // Подключаем шпиона ко всем историям по умолчанию
  args: { 
    onClick: fn() 
  },
  // ... твои argTypes и декораторы ...
};
```

**Как это проверить:** Открой Storybook, нажми на кнопку в песочнице, а затем посмотри в нижнюю панель на вкладку **Actions**. Ты увидишь, что событие `onClick` успешно зафиксировано, и сможешь развернуть его, чтобы посмотреть детали.

## 2. Viewport (Адаптивность)

Твоя кнопка может отлично смотреться на мониторе, но занимать слишком много места на телефоне.

В верхней панели Storybook есть **иконка экрана (Change the size of the preview)**. Если ты нажмешь на нее, то сможешь переключать холст между мобильным, планшетным и десктопным видами прямо на лету.

Но иногда мы хотим, чтобы определенная история *всегда* открывалась в мобильном виде (например, для специального мобильного меню). Это можно жестко прописать через `parameters`:

```tsx
// Добавь эту историю в конец Button.stories.tsx
export const Mobile: Story = {
  args: {
    label: 'Кнопка на мобильном',
    variant: 'primary',
  },
  parameters: {
    viewport: {
      // Запускаем эту историю на узком экране
      defaultViewport: 'mobile1',
    },
  },
};
```

Когда ты выберешь историю `Mobile` в сайдбаре, холст автоматически сузится до размеров смартфона.
