## Storybook | 6 уроков

Для уверенной работы со Storybook в твоем текущем стеке (React, TypeScript, CSS Modules) нам понадобится **6 структурированных уроков**.

Этого будет достаточно, чтобы научиться изолированно разрабатывать, тестировать и документировать UI-компоненты.

Вот подробный план нашего интенсива:

### План обучения Storybook

1. **Урок 1: Интеграция и интерфейс.** Правильный запуск Storybook внутри существующего проекта на Vite и разбор того, как устроена его панель управления.

2. 👉 **Урок 2: Написание первой истории (Story).** Создание изолированного компонента (например, UI-кнопки) и описание ее базового состояния с полной типизацией TypeScript.

3. **Урок 3: Интерактивные пропсы (Args).** Настройка вкладки Controls. Мы сделаем так, чтобы текст, цвет и размер компонента можно было менять кликами прямо в браузере без изменения кода.

4. **Урок 4: CSS Modules в изоляции.** Подключение и настройка локальных классов (CSS Modules), чтобы стили компонентов корректно подгружались в песочнице Storybook.

5. **Урок 5: Декораторы (Decorators).** Добавление глобальных оберток — например, центрирование компонентов на экране, добавление отступов или провайдеров тем.

6. **Урок 6: Полезные аддоны (Actions и Viewport).** Отслеживание кликов (эмуляция функций через Actions) и проверка адаптивности компонентов на мобильных и десктопных экранах.

## Урок 2: Написание первой истории (Story).

Storybook использует формат **Component Story Format (CSF)**. Это стандарт, в котором файлы историй пишутся на чистом TypeScript и экспортируют конфигурацию компонента.

### Шаг 1: Очистка проекта

Сначала давай удалим примеры, которые сгенерировал Storybook, чтобы они не засоряли проект.

* Смело удаляй всю папку **`src/stories`** (удалено).
* Сразу после этого твой сайдбар в Storybook опустеет — это нормально. Мы сейчас создадим свою папку для компонентов.

### Шаг 2: Создание компонента

Давай создадим простую кнопку с использованием TypeScript и CSS Modules.

**`src/components/Button/Button.tsx`**

```tsx
import styles from './Button.module.css';

interface ButtonProps {
  /** Текст внутри кнопки */
  label: string;
  /** Вариант внешнего вида */
  variant?: 'primary' | 'secondary';
}

export const Button = ({ label, variant = 'primary' }: ButtonProps) => {
  return (
    <button className={`${styles.btn} ${styles[variant]}`}>
      {label}
    </button>
  );
};
```

### Шаг 3: Написание истории (Story)

Файлы историй должны лежать рядом с компонентом и иметь расширение `.stories.tsx`. Storybook автоматически найдет их благодаря настройкам в `.storybook/main.ts`.

**`src/components/Button/Button.stories.tsx`**:

```tsx
import type { Meta, StoryObj } from '@storybook/react';
import { Button } from './Button';

// 1. Настройка Meta (Глобальная конфигурация для этого компонента)
const meta: Meta<typeof Button> = {
  title: 'UI/Button', // Путь и название в сайдбаре Storybook
  component: Button,  // Сам компонент
};

export default meta;

// 2. Типизация для историй
type Story = StoryObj<typeof Button>;

// 3. Создание конкретной истории (Primary)
export const Primary: Story = {
  args: {
    label: 'Главная кнопка',
    variant: 'primary',
  },
};
```

### Что здесь произошло?

1. **`Meta`**: Это дефолтный экспорт, который говорит Storybook: "Вот компонент `Button`, положи его в папку `UI` в сайдбаре".
2. **`StoryObj`**: Утилита из `@storybook/react`, которая подтягивает пропсы из `ButtonProps`. Благодаря ей TypeScript подскажет, если ты забудешь передать `label` или опечатаешься в `variant`.
3. **`args`**: Это стартовые пропсы. Мы передаем их компоненту, и Storybook рендерит кнопку с этими данными.

Как только ты сохранишь файл, Storybook автоматически обновит страницу. В левом меню появится папка **UI**, внутри неё — **Button**, а внутри — наша история **Primary**.
